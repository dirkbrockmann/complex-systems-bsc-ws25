If you are interested in learning more about agent-based modeling using Netlogo, 
the Santa Fe Institute offers an 

>[**introductory online course**](https://www.complexityexplorer.org/courses/84-fundamentals-of-netlogo) 

that you might find useful. 
The course covers the basics of Netlogo and how to build and analyze agent-based models.

The course is especially designed for beginners and provides a solid 
foundation in agent-based modeling concepts and techniques.

If you want to do some preparatory work before we start coding during
the lab course, it might be a good idea to check it out.
