In this exercise, you will simulate the diffusion of particles using NetLogo.

- setup button
- go button (check "forever")
- check on ticks

to setup
  ca
  reset-ticks
end


to go
  tick
end

- createturtles 100



to go
  tick
  ask turtles [
    forward 0.1
  ]
end


- set shape turtles "circle"
- make world larger



to go
  tick
  ask turtles [
    forward 0.5
    set heading heading + 1
  ]
end



to go
  tick
  ask turtles [
    forward 0.5
    set heading heading + random-float 60 - 30
  ]
end


to setup
  ca
  reset-ticks
  
  create-turtles N
  ask turtles [
    set shape "circle"
  ]
end


to go
  tick
  ask turtles [
    forward speed
    set heading heading + random-float wiggle - wiggle / 2
    ifelse pen? [pen-down] [pen-up]
  ]
end
