# Pattern formation in the brain


<img class=" aligncenter shadow size-50" src="images/brain.jpg">

Optical pathways in the brain: Each eye splits the visual field into left/right hemispheres. The axonal fibers from each of the two eyes and two hemispheres get distributed to the left/right visual cortices in the back of the brain, such that the left visual cortex receives information from the left visual field (from both eyes) and the right visual cortex from the right visual field.
{.text-intro}


---

# Ocular Dominance Maps


<img class=" aligncenter shadow size-50" src="images/ocular.jpg">

Cells in the visual cortex exhibit an ocular dominance. They exhibit the tendency to respond to stimuli presented to one eye more than those presented to the other eye. As a function of location on the visual cortex the ocular dominance patterns consists of stripes of a specific wave-length.
{.text-intro}

# Orientation maps in the visual cortex


<img class=" aligncenter shadow size-50" src="images/orientation.png">

Some cells in the visual cortex exhibit an orientation preference, they respond primarily to visual stimuli on the retina that are oriented in a specific direction. When the entire visual cortex is mapped and the orientation preference mapped in color for many species we see an orientation map. This map exhibits characteristic pinwheels, singularities in the orientation preference.

# First steps in Modelling: Voter Model
{ .aligncenter }

The original voter model is a discrete time model on a square lattice. Each lattice point has a binary state, it can either be $1$ or $-1$ for example. 
{.text-intro}

$$
u_{nm} = 1\qquad\text{or}\qquad u_{nm} = -1
$$
{.text-intro}

These are the rules for the voter model
{.text-intro}

0. The system (square lattice) is initialized in some configuration, e.g. with probability $1/2$ a lattice site is set to $1$ with probability $1/2$ set to $-1$.
1. Pick a random lattice site $n$
2. Pick one of its 8 neighbors at random (labeled $m$)
3. Site $n$ adopts the state of neighbor $m$
4. Go back to step 1
{.text-intro}

---

<!--:   .wrap   -->

# The Majority Model
{ .aligncenter }

This is similar to the Voter Model. But instead of adopting the "opinion" of a randomly chosen neighbor, a site adopts the majority opinion of the neighbors. When no majority is there, the site picks a random state (either $1$ or $-1$)
{.text-intro}

These are the rules for the voter model
{.text-intro}

0. The system (square lattice) is initialized in some configuation, e.g. with probability $1/2$ a lattice site is set to $1$ with probability $1/2$ set to $-1$.
1. Pick a random lattice site $n$
2. Compute the majority opinion of the neighborbood
3. Site $n$ adopts the state of the majority if it exists, when opinions are tied, the site picks the opinion of a randomly chose neighbor
4. Go back to step 1
{.text-intro}
